# Training Module 3: Cryptography

## Module focus

The supplied Module 3 presentations introduce cryptography as a way to protect information through encryption and decryption techniques.

## Learning objectives

The presentation identifies these objectives:

1. Understand cryptography.
2. Understand the principles of encryption and decryption.
3. Implement a basic encryption/decryption algorithm.
4. Secure a communication channel using cryptographic techniques.

## Concepts covered

### Encryption and decryption

Encryption transforms readable plaintext into ciphertext using an algorithm and key. Decryption uses the appropriate method and key to recover the original plaintext.

### Symmetric encryption

Symmetric encryption uses the same shared secret key for encryption and decryption. AES is presented as an example.

### Asymmetric encryption

Asymmetric cryptography uses a public/private key pair. The materials discuss confidentiality workflows and the use of public-key techniques for authentication and digital signatures.

### Hashing

Hashing produces a one-way digest used to support integrity checking. The materials distinguish hashing from encryption.

### Digital signatures and certificates

The materials explain how signatures support verification of integrity and key-based origin, and introduce certificates as a way of associating an identity or name with a public key.

### Secure protocols

The slides refer to TLS/HTTPS, SSH and VPNs, including the distinction between encrypted application traffic and visible connection metadata.

## Tools and examples

- OpenSSL
- Wireshark
- AES-256-CBC in the supplied file-encryption demonstration
- SHA-256 digest generation
- Caesar cipher with a shift of three

## Teaching approach reflected in the deck

The expanded instructor slides combine explanation, demonstration, learner practice, group discussion, troubleshooting, knowledge checks and a final exit ticket.
