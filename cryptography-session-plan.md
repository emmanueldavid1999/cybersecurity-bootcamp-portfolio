# Cryptography Module — Instructor Session Plan

The supplied expanded presentation contains a suggested five-hour instructor-led teaching plan, including two ten-minute breaks. The schedule below is reproduced as a plan from the slides, not as independently verified attendance or delivery records.

| Block | Suggested time | Focus |
|---|---:|---|
| 1 | 0:00–0:45 | Welcome, objectives, why cryptography matters, plaintext/ciphertext and keys |
| 2 | 0:45–1:35 | Encryption fundamentals, symmetric and asymmetric encryption, key handling |
| 3 | 1:35–2:15 | Hashing, integrity, digital signatures and certificates |
| Break | 2:15–2:25 | 10-minute break |
| 4 | 2:25–3:15 | Guided OpenSSL file encryption and verification |
| 5 | 3:15–4:05 | Caesar cipher exercise, weaknesses and discussion |
| Break | 4:05–4:15 | 10-minute break |
| 6 | 4:15–5:00 | Wireshark traffic observation, group challenge and assessment |

## Assessment and learner engagement

The deck proposes opening discussion questions, pair and group exercises, troubleshooting scenarios, a verbal knowledge check and a final exit ticket. The exit ticket asks learners to demonstrate file encryption/decryption, explain a difference between symmetric and asymmetric cryptography, describe a SHA-256 integrity check and identify a safe key-management practice.
